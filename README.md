# BREW - Belgian Requests & Execution Workflows

FHIR implementation guide (`hl7.fhir.be.workflow`) with Belgian guidance for request and Task based workflows, adapting the HL7 [Clinical Order Workflows (COW)](https://build.fhir.org/ig/HL7/fhir-cow-ig/) IG.

Canonical: https://www.ehealth.fgov.be/standards/fhir/workflow
